# 0011. SDL3 for windowing and input

- Status: Proposed
- Date: 2026-10-24
- Deciders: Felipe Carvajal Brown

## Context

The editor shell (phase B) needs windows, input and a Vulkan surface (ADR 0007). The studio is controller first, with the Xbox controller as the test device.

## Decision

SDL3 (zlib licence) handles windowing and input.

## Consequences

- Gamepad input uses SDL3's controller mappings, Xbox controller included.
- Vulkan surfaces come from SDL3.
- The editor uses Dear ImGui's SDL3 backend.

## Alternatives considered

- GLFW (zlib licence). Lighter, with thinner gamepad support.
