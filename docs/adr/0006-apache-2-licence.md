# 0006. Apache-2.0 licence

- Status: Proposed
- Date: 2026-10-24
- Deciders: Felipe Carvajal Brown

## Context

The repo is public and needs a licence.

## Decision

Apache License 2.0, Felipe's choice.

## Consequences

- `LICENSE` at the repo root holds the Apache-2.0 text.
- Third-party code brought in later keeps its own licence beside it.

## Alternatives considered

- MIT.
- GPL-3.0.
