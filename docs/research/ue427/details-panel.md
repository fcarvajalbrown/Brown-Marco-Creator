# Details panel

Source: https://dev.epicgames.com/documentation/en-us/unreal-engine/level-editor-details-panel-in-unreal-engine?application_version=4.27

- Shows information, utilities and functions for the current viewport selection: transform boxes, every editable property of the selected Actors, and type-specific tools (export to FBX, convert to another compatible type). [docs]
- Lists the Materials the selection uses and opens them for editing. [docs]
- The Actor's friendly name is edited at the top; the World Outliner search finds Actors by it. [docs]
- A Search Details box filters properties as you type. [docs]
- Favorites pin chosen properties to the top; experimental in 4.27, enabled under Editor Preferences > Experimental. [docs]
