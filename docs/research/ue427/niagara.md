# Niagara and Cascade

Source: https://dev.epicgames.com/documentation/en-us/unreal-engine/overview-of-niagara-effects-for-unreal-engine?application_version=4.27

- Both Cascade and Niagara make VFX in 4.27; Niagara is described as the next-generation system and works very differently. [docs]
- Niagara lets technical artists add functionality without a programmer. [docs]
- Four core parts: Systems, Emitters, Modules, Parameters. [docs]
- A System contains several Emitters combined into one effect, managed on a Timeline panel. [docs]
- An Emitter is a reusable container of Modules; one module-stack simulation can be drawn by several renderers in the same emitter (for example sprites and ribbons). [docs]
