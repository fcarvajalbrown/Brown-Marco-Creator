# UMG UI Designer

Source: https://dev.epicgames.com/documentation/en-us/unreal-engine/umg-ui-designer-for-unreal-engine?application_version=4.27

- Visual UI authoring for HUDs, menus and other interface graphics. [docs]
- Built from Widgets (buttons, checkboxes, sliders, progress bars and others), edited in a Widget Blueprint. [docs]
- The Widget Blueprint has a Designer tab for visual layout and a Graph tab for behaviour. [docs]

## For Brown Marco Creator

Phase J. Controller first: default focus and navigation order belong in the widget model from the start.
