# Materials and the material editor

Source: https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-materials?application_version=4.27

- A Material is an asset applied to a mesh that defines the surface: colour, shininess, transparency and more. [docs]
- Technically it computes how scene light interacts with the surface, from textures, math expressions and the material's own property settings. [docs]
- Related features in the docs index: Instanced Materials, Material Functions, Material Parameter Collections, Layered Materials and Material Layers, shading models, Customized UVs, the Material Analyzer. [docs]
