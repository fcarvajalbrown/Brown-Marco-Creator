# Animation Blueprints

Source: https://dev.epicgames.com/documentation/en-us/unreal-engine/animation-blueprints-in-unreal-engine?application_version=4.27

- A specialised Blueprint controlling a Skeletal Mesh's animation: blending, direct bone control, and logic that sets the final pose each frame. [docs]
- EventGraph updates values; AnimGraph uses them to drive State Machines, BlendSpaces and other nodes, blending sequences and poses and firing notifications. [docs]
- Sub Anim Instance nodes include another Animation Blueprint's logic, to share and split large graphs. [docs]
