# Blueprint visual scripting

Source: https://dev.epicgames.com/documentation/en-us/unreal-engine/blueprints-visual-scripting-in-unreal-engine?application_version=4.27

- A complete gameplay scripting system with a node-based interface inside the editor, used to define object-oriented classes. [docs]
- Gives designers "virtually the full range of concepts and tools generally only available to programmers". [docs]
- Blueprint-specific markup in C++ lets programmers build base systems that designers extend. [docs]
- Related features in the docs index: Level Blueprint, Event Dispatchers, Blueprint Interfaces, comments and breakpoints, the Math Expression node, random streams. [docs]
