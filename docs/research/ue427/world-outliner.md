# World Outliner

Source: https://dev.epicgames.com/documentation/en-us/unreal-engine/outliner-in-unreal-engine?application_version=4.27

- Shows every Actor in the scene as a hierarchical tree; Actors are selected and modified from it. [docs]
- An Info dropdown adds a column for Levels, Layers or ID Names. [docs]
- Left-click selects; right-click opens the same context menu as the viewport; dragging one Actor onto another attaches it. [docs]
- Search matches partially; several words must all match; '-' excludes a term, '+' forces an exact term, double quotes force an exact match on the long name; Info columns are searchable too, e.g. '+[LevelName]'. [docs]
