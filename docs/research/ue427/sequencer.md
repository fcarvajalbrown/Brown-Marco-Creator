# Sequencer

Source: https://dev.epicgames.com/documentation/en-us/unreal-engine/cinematics-and-movie-making-in-unreal-engine?application_version=4.27

- Sequencer is UE4's multi-track, non-linear editor for creating and previewing cinematic sequences in real time. [docs]
- Used to pilot cameras for fly-throughs, animate lights, objects and characters, and render output sequences. [docs]
- Rendering and batch rendering go through the Movie Render Queue. [docs]

## For Brown Marco Creator

Phase J. Level sequences with camera, transform and animation tracks first; Movie Render Queue goes to the cut-list review.
